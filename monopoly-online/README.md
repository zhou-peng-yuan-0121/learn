# 🎲 大富翁 · 多人联机

经典地产大亨玩法，浏览器即玩，支持 2~6 人在同一局域网内实时联机对战。

## 功能

- **多人联机**：房间制（4 位房间码），同一 Wi-Fi 下的朋友输入房间码即可加入，最多 6 人
- **AI 机器人**：房主可在等待界面一键添加最多 4 个 AI 玩家（可随时移除），一个人也能开整局
- **服务端权威**：所有掷骰、交易、破产判定在服务器执行，防作弊、状态一致
- **经典规则**：
  - 40 格经典棋盘（8 组彩色地产 + 4 车站 + 2 公用事业）
  - 掷骰子移动，双数可连掷，连续三次双数入狱
  - 买地、过路费、同色组翻倍租金、建房子/旅馆、卖房
  - 机会卡（金钱/移动/入狱事件）、所得税、奢侈税
  - 监狱（掷双数出狱 / 三次强制保释）、破产移交地产
  - 最后存活的玩家获胜；超过 300 回合按总资产定胜负
- **实时同步**：棋盘、玩家位置、房产、金钱、日志全端实时更新
- **断线重连**：刷新页面自动恢复身份；断线玩家由服务器自动代打，不卡局
- **内置聊天**：对局中随时交流

## 快速开始

需要 [Node.js](https://nodejs.org/) 18 或更高版本（已安装可跳过第一步）。

```bash
# 1. 安装依赖（首次）
npm install

# 2. 启动服务
npm start

# 3. 打开浏览器访问
#    本机：   http://localhost:3000
#    局域网： http://<你的电脑IP>:3000
```

启动后控制台会打印本机访问地址。查看本机 IP：

- Windows：`ipconfig` 里找 IPv4 地址（如 192.168.1.5）
- 把 IP 地址（带端口）发给同一 Wi-Fi 下的朋友即可一起玩

> 端口默认为 3000，可用环境变量修改：`set PORT=8080 && npm start`

## 玩法说明

1. 输入昵称 → **创建房间**（成为房主）或输入房间码**加入房间**
2. 房主在等待界面点 **🤖 添加 AI 玩家** 可补齐人数（最多 4 个 AI），点 **🚀 开始游戏** 开玩（至少 2 人，可全真人/全 AI/混合）
3. 轮到你时点 **🎲 掷骰子**；落到无主地产可**购买**（15 秒内决定，超时自动放弃）
4. 掷出双数可再掷一次；已掷完点 **结束回合**
5. 拥有整套颜色组后，回合中点击自己地皮可**建房**（右键**出售**），房子越多租金越贵
6. 其他玩家落到你的地产上需付租金；现金不足则破产出局，地产移交给债主
7. 最后一名未破产玩家获胜 🏆

> AI 玩家由服务器自动代打（自动掷骰、购买、建房），节奏约每步 0.4 秒，行动全程可见。

## 目录结构

```

├── game.js            # 核心游戏逻辑（棋盘/回合/租金/破产，可独立测试）

```

## 测试

```bash
npm test            # 3 名真人玩家自动玩完整局（联机流程/购买/建房/收租/破产/胜负）
node test/simulate_bot.js   # 1 名真人 + 3 个 AI 机器人对局（AI 自动行动验证）
```

测试脚本会启动临时服务端，模拟玩家通过 WebSocket 实时对战，自动断言关键流程正常。

## 已实现的简化（与经典版差异）

- 无拍卖：放弃购买的地产直接保持无主
- 免费停车：不积累奖金池
- 无免狱牌；监狱保释金固定 50
- 破产时地产优先移交给债主，其余回归无主（不抵押融资）
- 单服务器内存保存房间，重启服务后房间重置
